# French writing rules

This rule set adapts the Open Humanizer editorial checks to French. It flags common formulaic, promotional, vague, and tool-generated patterns. It is an editorial quality check, not an AI detector.

Use it with:

```text
python -m humanizer.cli article-fr.md --rules rules/french_writing_rules.json
```

The suggestions are written in English so the tool output remains consistent. The matched phrases are French and can be extended in `rules/french_writing_rules.json`.

The checks cover:

- promotional and inflated French vocabulary;
- unsupported importance claims;
- vague attribution;
- superficial participle-present analysis;
- automatic contrast formulas;
- placeholders;
- internal AI markers;
- assistant language;
- em dashes.

Do not treat a flagged phrase as proof that a text was generated by AI. Review it against the source, author voice, and evidence.
